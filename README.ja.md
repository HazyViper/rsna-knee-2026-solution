# RSNA Knee Abnormality Detection 2026: 一人参加のコードと測ったこと（日本語の要約）

本文は [README.md](README.md)（英語）です。ここはその要約です。

## 結果

- 最終 623 位 / 6,300（銅）。2026-10-27 に Kaggle が 125 チームを外して非公開の順位を並べ直した後の順位です。
- **順位を見る前に**: 選んだ 2 本（提出 55・57）は、どちらも他人の公開ノートブックの上に立っています。
  55 は公開ノートブックをそのまま、57 は公開ノートブック 0.7 と自前の束 0.3 の順位の混合で、非公開はどちらも 0.942 です。
  自前のモデルだけでは、締め前の最高は提出 48 の非公開 0.939 でした。
- 締め後の Late Submission（順位には載りません）: 21 位のチームが締めの後に公開したラベルで、全体の膝のメンバー 5 本を学習し直した
  L14 が非公開 0.954、推論でだけ注意を鋭くした L34 が 0.955 でした。L14 との差 +1 は雑音の内です。

## 中身

- [inference/](inference/): L34 のノートブック（公開版とバイト一致）、埋め込まれたソースの展開、1 study の処理の説明。
- [src/eval/metrics.py](src/eval/metrics.py)・[tests/](tests/): 検証の指標（施設層内の一致度 c、ペア・ブートストラップ）とそのテスト。
- [labels/](labels/): 報告書からソフトラベルを作ったプロンプト。58 例から測った節は伏せています。
- 無いもの: 学習コード・自前のラベル・study 単位のデータ。競技の規約 4.b と RSNA MIRA の 4・6 で公開できないためです。
  重みは Kaggle の Dataset にあります。

## 方法

- 学習用の 4,407 study のうち、主催者のラベルが付いているのは 58 だけです。全 study に、9 言語のどれかで書かれた報告書があります。
  LLM（Claude）が報告書を読み、12 の所見に連続値と根拠の引用を付けました。メンバーはこのラベルで学習しました。
- メンバーは 2.5D の画像モデルです。隣り合う 3 枚で 1 窓、21 窓を注意で束ねます。全体の膝は CoAtNet（矢状断 80 枚、冠状断・軸位 40 枚）と
  ConvNeXt-Small（冠状断・軸位）で、ほかに部位の専門メンバー（クロップ・タイル）があります。右膝の冠状断と軸位は鏡映して、内側の向きを揃えます。
- 束ね方: fold ごとにラベルごとの線形の stacker を当て、5 fold の確率を平均します。
- 検証の指標: 施設層内の一致度 c です。同じ機種の中の対だけを数え、51 層を合わせてから 1 回割ります。
  締め後に測ると、自前の束 18 本の非公開の順を Spearman 0.998 で再現していました。

## 効いたこと

1. 教師（学習のラベル）。21 位の、画像を読んだラベルに替えると、全体の膝のメンバー 5 本が単独で非公開 +18〜+24 目盛、束で +15 目盛上がりました。
2. ただし、報告書由来のラベルで測る指標にはこの差が見えませんでした（7 対のうち 6 対で逆の向き）。教師の良し悪しは、LB か真ラベルでしか測れません。
3. スライスを IPP の順に並べ、左右の向きを揃えること。58 例の macro AUC で +0.055 でした（初期の CNN、10 seed の対で 10 / 10）。
4. 冠状断と軸位は、入力のチャネルとしては効かず、別のメンバーとしては効きました。

## 効かなかったこと

締め後に 1 因子ずつ非公開で比べた手（レシピ・損失・頭・撮像条件の条件づけ・後処理・ほかのラベル）の多くは、区別できませんでした。
区別できた例外は、推論でだけ FiLM を外す手（+3）と、凍結した backbone の上でヘッドを付け直す手（−5）です。

## 教訓

1. 上限は教師にありました。締め前のラベルはすべて報告書の文から作りましたが、読んだ上位の記事 13 本のうち 12 本は、画像を読む LLM を教師にしていました。
   画像を読むラベルは $48.49 で作れたのに、作ったのは締めの後でした。
2. 指標と最終 2 本の選び方は正しく働きました。足りなかったのは中身です。
3. 1 因子の変更の多くは、1 対の分解能より小さい差しか生みません。測る前に大きさを見積もるべきです。
4. 格子の首位の見かけの利得は、大部分が選んだことの偏りでした。
5. 機種群をまるごと外すと、無作為に外した場合より c が 0.009〜0.013 下がりました。
